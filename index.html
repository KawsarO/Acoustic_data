    3. How it works
    

    Each packet starts with a 100 ms linear chirp. The receiver cross-correlates the mic audio against a copy of that chirp, and the correlation peak gives exact symbol timing. Then come an 18-byte header (type, length, image metadata) and the payload in 32-byte blocks. Every block has a CRC-16 and 12 Reed-Solomon parity bytes, so the receiver can fix up to 6 wrong bytes per block, or up to 12 if it can tell which bytes it's unsure about.
    

    Images are shrunk (32–128 px), quantized to 1, 2 or 4 bits per pixel with Floyd–Steinberg dithering (or JPEG-compressed). Gray formats get an automatic contrast stretch first, so 1-bit dithering keeps the shapes readable, and sent rows-first in interlaced order (every 8th row, then every 4th, and so on). Each 96-byte packet's header carries the image ID, format, width, height and packet number, so every packet is self-contained.
    

    Each byte becomes two 4-bit symbols, and each symbol is sent as one of 16 tones (16-MFSK). The phase stays continuous between tones, so there are no audible clicks. The receiver skips a short guard interval at the start of every symbol, where room echoes of the previous tone land. It then measures all 16 tones with a Goertzel filter and picks the strongest one.
